# Uzbek World Cup Telegram Bot

Автоматический бот для публикации контента в Telegram канал о сборной Узбекистана на ЧМ-2026.

## 🚀 Быстрый старт

### Шаг 1: Установи Python
1. Скачай Python с https://www.python.org/downloads/
2. При установке поставь галочку "Add Python to PATH"
3. Установи

### Шаг 2: Установи библиотеки
1. Открой папку `FIFA` в проводнике
2. В адресной строке напиши `cmd` и нажми Enter
3. В открывшемся окне напиши:
```
pip install -r requirements.txt
```
4. Дождись установки

### Шаг 3: Запусти бота
В том же окне напиши:
```
python bot.py
```

## ✅ Что делает бот

- ⏰ Публикует посты каждые 30 минут (48 постов в день)
- 📊 Обратный отсчет до матчей
- ⭐ Информация об игроках
- 📢 Напоминания о матчах
- 💪 Мотивационные посты
- 📈 Факты о сборной
- 👥 Посты о сообществе

## 🔧 Как переключить на основной канал

Открой файл `bot.py` в блокноте и найди строку:
```python
CHANNEL_ID = "@uzbekworld_test"
```

Замени на:
```python
CHANNEL_ID = "@uzbekworldcup"
```

Сохрани файл и перезапусти бота.

## 📝 Как добавить свой контент

В файле `bot.py` найди раздел `POST_TEMPLATES` и добавь свои шаблоны постов.

## ⚠️ Важно

- Бот должен быть администратором канала
- Компьютер должен быть включен для работы бота
- Для 24/7 работы нужен хостинг (инструкция ниже)
