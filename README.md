# 🇺🇿 Uzbekistan World Cup 2026 Bot

Многоязычный Telegram бот для фанатов сборной Узбекистана на ЧМ-2026.

## 🌐 Особенности

- **3 языка**: O'zbekcha 🇺🇿, Русский 🇷🇺, English 🇬🇧
- **Интерактивное меню**: расписание, игроки, таблица группы
- **Watch Party Finder**: поиск по городам
- **Админ-панель**: WAR ROOM отчёты, статистика
- **Сохранение языка**: бот помнит выбор каждого пользователя

## 🚀 Деплой на Railway - ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1: Push на GitHub ✅
```bash
git add .
git commit -m "Production bot ready"
git push origin main
```

### Шаг 2: Создание проекта на Railway

1. **Откройте** https://railway.com
2. **Войдите** через GitHub
3. **Нажмите** "New Project"
4. **Выберите** "Deploy from GitHub repo"
5. **Найдите** репозиторий `Madko111/FIFA`
6. **Нажмите** "Deploy Now"

### Шаг 3: Настройка переменных окружения

1. **В проекте Railway** нажмите на ваш сервис
2. **Перейдите** на вкладку "Variables"
3. **Добавьте** следующие переменные:

```
BOT_TOKEN=8947264177:AAHA57URuzWpHEJYfXp-IF08R2kLpTM_lSw
CHANNEL_ID=@uzbekworld_test
ADMIN_USER_ID=5345007811,573901881,78310521
POST_INTERVAL_MINUTES=30
```

4. **Нажмите** "Add" после каждой переменной

### Шаг 4: Проверка деплоя

1. **Перейдите** на вкладку "Deployments"
2. **Откройте** последний деплой
3. **Проверьте логи**, должно быть:
   ```
   🚀 Bot ishga tushmoqda...
   ✅ Bot ishga tushdi!
   ```
4. **Готово!** Бот работает 24/7

## 📝 Локальный запуск (для разработки)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск
python bot.py
```

## 🔐 Управление администраторами

**На Railway:**
1. Variables → Найдите `ADMIN_USER_ID`
2. Измените значение: `123456,789012,345678`
3. Сохраните → Railway автоматически перезапустит бот

**Локально:**
Откройте `.env`:
```
ADMIN_USER_ID=123456,789012,345678
```

Узнать Telegram ID: напишите боту `/start`

Подробнее: `ADMIN_GUIDE.md`
